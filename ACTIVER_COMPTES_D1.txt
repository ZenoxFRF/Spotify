ACTIVER LES COMPTES JOUEURS (CLOUDFLARE D1)

1. Dans Cloudflare, ouvre Storage & databases > D1 SQL Database.
2. Clique Create database, nomme-la : blind-test-db, puis Create.
3. Ouvre ton projet Spotify Blind Test dans Workers & Pages.
4. Onglet Bindings > Add binding > D1 database.
5. Variable name : DB (en majuscules). Sélectionne blind-test-db, puis Add binding.
6. Déploie le ZIP avec New deployment.

C'est tout : les tables sont créées automatiquement lors de la première création
de compte. Les mots de passe ne sont jamais enregistrés en clair : ils sont hachés
avec PBKDF2 dans D1. Le cookie de connexion est sécurisé et valable 30 jours.

Ne supprime pas la liaison DB : sans elle, le bouton Mon compte ne peut pas créer
de comptes.
