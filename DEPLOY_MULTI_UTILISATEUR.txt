BLIND TEST SPOTIFY — MULTI-UTILISATEUR
=======================================

Le code est prêt. Les comptes D1 existants sont conservés.

IMPORTANT : Spotify bloque les autres comptes tant qu'ils ne sont pas autorisés
dans l'application Spotify en mode Development. Ce n'est pas contournable par
du code.

1. Va sur https://developer.spotify.com/dashboard
2. Ouvre l'application ayant le Client ID : 4bdba1e2396248b58dfaba572af2b6af
3. Settings > Users and Access > Add new user
4. Ajoute l'adresse e-mail Spotify de chaque joueur (maximum 5 comptes au total
   en mode Development).
5. Vérifie que https://spotify.vzmgen.xyz/ est bien présent dans Redirect URIs.

Ensuite, redéploie ce ZIP avec Cloudflare Pages (Git/Wrangler), en gardant le
binding D1 existant : DB -> blind-test-db.

Chaque joueur clique « Se connecter à Spotify » puis choisit son propre compte.
Chaque joueur doit disposer de Spotify Premium.

Pour accueillir plus de 5 comptes, demande l'Extended Quota à Spotify depuis le
tableau de bord. Cette application de lecture doit rester conforme aux règles
Spotify (pas de diffusion publique ni commerciale).
