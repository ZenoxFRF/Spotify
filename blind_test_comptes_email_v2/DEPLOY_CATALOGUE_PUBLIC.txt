BLIND TEST PUBLIC — SANS SPOTIFY
================================

Les joueurs n'ont besoin d'aucun compte musical. Cette version recherche et lit
les morceaux disponibles publiquement sur Audius.

OPTIONNEL : AJOUTER JAMENDO (catalogue plus grand)
--------------------------------------------------
1. Crée une application sur https://devportal.jamendo.com/.
2. Dans Cloudflare Pages > Settings > Environment variables, ajoute :
     JAMENDO_CLIENT_ID = ton identifiant Jamendo
3. Redéploie le projet.

L'identifiant Jamendo reste côté Cloudflare : il n'est jamais envoyé au navigateur.
Sans cette variable, le site fonctionne déjà avec Audius seul.

GARDE LE BINDING D1 EXISTANT :
  DB -> blind-test-db

ATTENTION
---------
Ces catalogues publics ne contiennent pas obligatoirement les artistes les plus
connus. Seuls les titres mis légalement à disposition par leurs artistes peuvent
être lus. Il n'existe pas de catalogue légal gratuit et ouvert contenant tous les
titres commerciaux sans connexion des joueurs.
