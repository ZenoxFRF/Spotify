CORRECTION DU PROBLEME D1
==========================

Le projet utilise maintenant les Pages Functions standard :
  functions/api/register.js
  functions/api/login.js
  functions/api/session.js
  functions/api/logout.js

IMPORTANT :
Cloudflare indique que les Functions ne sont pas prises en charge avec le
Direct Upload de Pages. Pour ce projet, déploie avec une intégration Git
(GitHub/GitLab) ou avec Wrangler.

Dans Cloudflare :
1. Garde le binding Production :
   Type = D1 database
   Variable name = DB
   Database = blind-test-db

2. Mets ce dossier dans un dépôt GitHub.
3. Dans Workers & Pages > ton projet > Settings > Builds > Git repository,
   connecte le dépôt.
4. Déploie le projet.
5. Vérifie que le binding DB est présent en Production.
6. Recharge https://spotify.vzmgen.xyz/

TEST :
Ouvre directement :
https://spotify.vzmgen.xyz/api/session

Si D1 fonctionne, tu dois recevoir :
{"user":null}

Si tu reçois une erreur indiquant que D1 n'est pas disponible, le binding
n'est pas attaché au déploiement Production.

La base crée automatiquement les tables users et sessions au premier appel.
